Pierwsze uruchomienie (lokalne)

1
Zależności PHP
composer install
2
Plik .env i klucz aplikacji
cp .env.example .env
php artisan key:generate
3
Utwórz pliki baz SQLite
touch database/database.sqlite
touch database/blog.sqlite
4
Uruchom migracje
php artisan migrate
php artisan migrate --database=blog --path=database/migrations/blog
5
Symlink storage
php artisan storage:link
6
Zbuduj frontend
npm install
npm run dev
7
Serwer deweloperski
php artisan serve
Panel: http://localhost:8000/{ADMIN_PREFIX} (domyślnie /admin)

Wdrożenie produkcyjne — deploy.sh

Skrypt realizuje 7-krokowy proces z trybem serwisowym, kopią zapasową baz i rollbackiem przy błędzie.

./deploy.sh

Skrypt pyta o potwierdzenie i pokazuje listę nadchodzących commitów przed wdrożeniem.

Kroki deploy.sh

1
Tryb serwisowy
php85 artisan down --render="errors::503" --retry=30 — strona niewidoczna dla użytkowników.
2
Kopia zapasowa baz SQLite
Obie bazy kopiowane do /tmp/feer-db-YYYYMMDD-HHMMSS.sqlite przed git pull.
3
Git pull
git pull origin main — po pobraniu bazy są przywracane z kopii (git checkout je resetuje).
4
Composer update
--no-dev --optimize-autoloader; przy błędzie skrypt kontynuuje i podaje instrukcję ręczną.
5
Build frontend (npm)
npm ci && npm run build — generuje pliki do public/build/.
6
Migracje obu baz
php85 artisan migrate --force
php85 artisan migrate --force --database=blog --path=database/migrations/blog
7
Cache i wyłączenie trybu serwisowego
optimize:clear → optimize → artisan up

Lokalny test skryptu: PHP_BIN=php COMPOSER_BIN=composer NPM_BIN=npm ./deploy.sh

Rollback po błędzie

Skrypt ma ustawiony trap ERR — tryb serwisowy jest wyłączany automatycznie. Ręczne przywrócenie bazy:

cp /tmp/feer-db-20260101-120000.sqlite database/database.sqlite
cp /tmp/feer-blog-db-20260101-120000.sqlite database/blog.sqlite
php85 artisan optimize:clear

Microsoft 365 SSO — konfiguracja Azure

1
Utwórz rejestrację aplikacji
Azure Portal → Microsoft Entra ID → Rejestracje aplikacji → Nowa rejestracja.
2
Ustaw Redirect URI (Web)
https://feer.org.pl/auth/microsoft/callback
https://feer.org.pl/auth/member/microsoft/callback
3
Utwórz Client Secret
Certyfikaty i wpisy tajne → Nowy wpis tajny klienta → skopiuj wartość (pokazywana raz).
4
Skopiuj dane do .env
MICROSOFT_CLIENT_ID=<ID aplikacji>
MICROSOFT_CLIENT_SECRET=<Secret>
MICROSOFT_TENANT_ID=<ID tenanta lub "common">
⚠
Ograniczenie logowania do domeny org: Ustaw MICROSOFT_TENANT_ID na konkretny ID tenanta (zamiast common), aby zablokować zewnętrzne konta Microsoft.

Pozostałe polecenia

Prawa dostępu

chmod -R 775 storage bootstrap/cache
chown -R www-data:www-data storage bootstrap/cache

Kolejka zadań (Queue Worker)

php85 artisan queue:work --tries=3 --timeout=60

Scheduler (cron)

* * * * * www-data php85 /ścieżka/do/artisan schedule:run >> /dev/null 2>&1

Cache — ręczne odświeżenie

php85 artisan optimize:clear   # czyści
php85 artisan optimize          # buduje (config + routes + views)

Migracje ręczne

php85 artisan migrate --force
php85 artisan migrate --force --database=blog --path=database/migrations/blog
🔴
Na serwerze produkcyjnym: zawsze używaj php85, nigdy samego php — może wskazywać na starszą wersję.
